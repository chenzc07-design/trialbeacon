# TrialBeacon 首页视觉参考研究

## NCI Design System

来源：https://designsystem.cancer.gov/about

关键原则：NCI Design System 强调一致的视觉语言，帮助用户高效找到癌症相关内容；视觉应具有包容性和代表性；可访问性是设计过程的核心原则。NCI 的数字策略还强调 audience-focused、data-informed、collaborative、agile、accessible to all。

对 TrialBeacon 的启示：癌种图形不应使用恐怖、过度写实或容易引发不适的病灶照片，而应采用统一风格、低刺激、可识别的医学抽象图形；首页首屏应该从纯深色数据面板转为更明亮、具层次且仍然保持信息导向的视觉。

## Cancer Research UK

来源：https://www.cancerresearchuk.org/

公开首页采用明亮导航、强视觉主图和清晰行动按钮，主图通过渐变遮罩承载大标题；图片服务于研究、患者和行动叙事，而不是作为无关装饰。页面信息区块之间留有明显留白，但核心入口具有清晰视觉锚点。

对 TrialBeacon 的启示：可以保留实验室和照护团队图片，但顶部应使用更明亮的研究影像作为主视觉，减少纯黑/深海军蓝的大面积覆盖；癌种入口可使用柔和的医学纹理缩略图，而不必使用线性器官图标。

## 当前改版方向

1. 顶部首屏：浅色研究型背景 + 右侧研究影像 + 深色文字和白色数据卡，降低压迫感。
2. 癌种卡片：优先使用已有 `public/cancer-*.png` 的抽象医学纹理缩略图；保留统一尺寸、低饱和度和不刺激的视觉语言。
3. 图形策略：不使用病灶、手术或真实疾病组织图片；采用抽象细胞、分子、波纹和组织纹理，保持专业与亲和。
4. 交互与可访问性：图片作为装饰或辅助识别，癌种名称、记录数量和链接仍是主要信息，不依赖图片传达关键内容。
